# Ralph Progress Log — Admin Backend Overhaul
Started: 2026-05-20

## Codebase Patterns

### Admin edge-function auth gate (discovered 2026-05-20)
Pattern for admin-only edge functions:
1. `handleCors(req)` → early return on OPTIONS
2. `checkRateLimit(req, { windowMs, max, message })` → 429 + Retry-After
3. Reject non-GET/POST → 405
4. Build service-role client with `Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")`
5. Read `Authorization: Bearer <token>`, call `supabase.auth.getUser(token)`
6. Lookup `profiles.role` and require `admin` or `root_admin`
7. Run queries, return JSON with `Cache-Control: private, max-age=N`
Reference: `supabase/functions/process-stripe-refund/index.ts` and the new
`supabase/functions/admin-home-stats/index.ts`.

### TanStack hook for admin data (discovered 2026-05-20)
Use `supabase.functions.invoke<ResponseType>("fn-name", { body })` (not raw fetch)
so auth headers are attached automatically. Match `staleTime` to the edge
function's `Cache-Control: max-age` to avoid wasted re-fetches. Disable
`refetchOnWindowFocus` for admin dashboards — focus-thrash is noise here.

  AdminSocial.tsx, AdminEmail.tsx, AdminDeals.tsx, AdminPartnerships.tsx,

Files modified:
- `src/components/admin/AdminNav.tsx` (full rewrite)
- `src/App.tsx` (added 9 lazyWithRetry imports + Route entries)

**Learnings for future iterations:**
- `lazyWithRetry()` is the local helper in App.tsx that wraps React.lazy
  with chunk-reload retry. Use it (not raw `lazy()`) for all new admin
  pages so Cloudflare cache purges don't strand users on "Loading…".
- ROLE_RANK comparator pattern: keep an enum-like map in the nav module
  and use `ROLE_RANK[user] >= ROLE_RANK[group.minRole]`. Easier to read
  than ad-hoc `includes(["admin", "root_admin"])` arrays.
- AdminPlaceholder pattern: when registering routes ahead of full
  implementation, prefer a single shared placeholder component over 9
  near-identical placeholder pages. Each page becomes a 5-line wrapper
  that names its tracking story.
