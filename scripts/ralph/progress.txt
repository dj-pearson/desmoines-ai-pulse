## 2026-06-13 - WEB-AUTO-007 (AI article pipeline: topic → draft → quality gate → auto-publish)
Fresh local-SEO content now writes and publishes itself daily; humans only see the ambiguous middle.

What was implemented:
- **New self-contained `auto-article-pipeline` edge fn** (daily cron `auto-article-pipeline-daily` 13:00 UTC ≈ 7-8am Central, migration 20260612000013). Auth-gated with requireAdminOrApiKey (cron service-role bearer + admin re-run JWT pass), wrapped in the WEB-AUTO-001 jobRunner. Runs under default verify_jwt=true — NOT added to config.toml (matches data-quality-heal/dedupe-content precedent).
- **Pipeline steps:** (1) TOPIC — Claude suggests 6 locally-relevant topics; deduped against the last 100 article titles (drop slug collisions + >=0.7 Jaccard on title tokens), pick highest `seo_potential`. (2) DRAFT — Claude writes a full local-SEO markdown article using a condensed Des-Moines local-context block. (3) SCORE 0-100 + reasons[] — word count>=400 (hard -60 below), Des Moines/Iowa mention count, title similarity-to-existing, readability (avg words/sentence), SEO completeness, + a lightweight Claude SAFETY check that **fails safe** (can't screen → held for review, never auto-published). (4) DECISION — `>=80` & under daily cap → **published**; `50-79` (or >=80 with cap hit) → **draft** (review_status=pending_review) with score+reasons; `<50` or unsafe → **discarded** (attempt logged in jobRunner metadata, no row written).
- **Daily cap = 1 auto-PUBLISHED/day** (counts auto_generated+published rows since UTC midnight; extra high-scorers fall back to draft).
- **Pause flag = single system_settings row** (setting_type='article_pipeline', settings.paused). Admin toggles it from a new **Pause/Resume AI Pipeline** button in Admin→Articles (ArticlesManager) or via SQL — no code change.
- **Slug:** insert with `slug:''` so the existing `auto_generate_article_slug_trigger` (fires `WHEN slug IS NULL OR slug=''`) generates a unique slug. author_id=null (system-authored).
- **Sitemap + newsletter pool:** no wiring needed — `generate-sitemap` already selects `status='published'`, and publishing = `status='published'` puts the row in the pool the future digest (WEB-AUTO-008) queries.
- **Admin visibility:** ArticlesManager shows a purple **AI {score}** badge (reasons on hover) on auto_generated rows; `auto-article-pipeline` added to JobHealthPanel RERUNNABLE.
