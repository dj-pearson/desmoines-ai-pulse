- **Learnings for future iterations:**
  - campaign_status has no pending_review label (WEB-ADS-004). Any plpgsql that
    compares status against that literal raises 22P02 at runtime, even though
    CREATE FUNCTION succeeds. Compare status::text until the enum is extended.
  - ALTER TYPE ... ADD VALUE and a statement that USES the new value cannot share
    a transaction, and each migration file is one transaction. Put the enum
    change in its own file ahead of anything that selects on it.
  - Deno invariant tests need --allow-read; CI lists each test file explicitly
    in subscription-sync-tests.yml, so a new test must be added there or it
    never runs. `npm i -g deno@2.9.6` works in this container.
  - Smoke lane (playwright.smoke.config.ts) only runs files matching
    route-smoke|cookie-consent, so new smoke tests go into route-smoke.spec.ts.
  - No Supabase credentials in this container: migrations cannot be applied or
    probed. Record expected outcomes and leave the owner a one-line action.
