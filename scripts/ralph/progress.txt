Register the fn in `supabase/config.toml` with `verify_jwt = false` so your own auth gate runs. `Deno.serve(async (req)=>{ const c=handleCors(req); if(c) return c; const cors=getCorsHeaders(origin); const fail=await requireAdminOrApiKey(req,cors); if(fail) return fail; ... })`.
- **jobRunner:** `await runJob('name', async (ctx)=>{ ctx.processed(n); ctx.failed(m); ctx.meta({...}); return summary }, {maxAttempts})`. Returns `{ok,status,result,...}`. `ok=true` even when status==='partial' (ctx.failed>0 but fn didn't throw). Never throws. Counts/metadata land in `automation_job_runs` + the Job Health panel. Add re-runnable jobs to `RERUNNABLE` in JobHealthPanel.tsx.
- **pg_cron migration pattern:** wrap in `IF EXISTS (SELECT 1 FROM pg_extension WHERE extname='pg_cron')`, `cron.unschedule(name) WHERE EXISTS(... )` then `cron.schedule(name, 'min hour dom mon dow', $cron$ SELECT net.http_post(url := current_setting('app.settings.supabase_url')||'/functions/v1/<fn>', headers := jsonb_build_object('Authorization','Bearer '||current_setting('app.settings.supabase_service_role_key'),'Content-Type','application/json','x-trigger-source','cron')) $cron$)`.
- **Admin-gated SECURITY DEFINER RPC (callable by BOTH the service-role edge fn and admin users):** pin `SET search_path = public, pg_temp`; gate with `IF auth.uid() IS NOT NULL AND NOT public.is_admin() THEN RAISE EXCEPTION ...` (service role → uid null → allowed; non-admin authenticated → blocked); then `REVOKE ALL ON FUNCTION ... FROM PUBLIC; GRANT EXECUTE ... TO authenticated, service_role`. `public.is_admin()` (no-arg, uses auth.uid()) already exists.
- **Trigram fuzzy infra:** pg_trgm enabled + GIN indexes on `events(title,venue,location)` and `restaurants(name,cuisine,location)` (migration 20250107000007). Use `a.col % b.col` (index-probing operator) + `similarity(a.col,b.col) >= threshold`. Compute geo distance in plain SQL via haversine (acos/sin/cos/radians) from latitude/longitude — avoids a PostGIS dependency.
- **Repointing all child FKs generically** (merge/dedupe/delete-with-children): loop `pg_constraint` where `contype='f' AND confrelid=<table>::regclass AND array_length(conkey,1)=1` and the referenced col is `id`; `EXECUTE format('UPDATE public.%I SET %I=$1 WHERE %I=$2', child_table, child_col, child_col)`. Catch `unique_violation OR check_violation` and fall back to a ctid row-by-row move that DELETEs only the genuine collisions.
- **Admin tabs:** add `{id,label,icon}` to `CONTENT_TABS` (AdminContent.tsx) or `SYSTEM_TABS` (AdminSystem.tsx) + render `{activeTab === "id" && <Panel/>}`. Panels: `useQuery` with `refetchInterval`, admin-gated by RLS `is_admin()` + `useAdminAuth()`.
- **Favorites are NOT a `favorites` table** — event favorites live in `user_event_interactions (event_id, interaction_type='favorite')`.
- **Lint:** `npm run lint` (`eslint .`) exits 1 due to a PRE-EXISTING parser false-positive at `src/components/media/VideoPlayer.tsx:587` (',' expected) — tsc accepts the file; it predates these stories. - **Deno parse check (no Supabase in container):** `npx esbuild supabase/functions/<fn>/index.ts --bundle --external:https://* --format=esm --platform=neutral --outfile=/dev/null`. Migrations can't be applied locally — write them additive + idempotent (IF NOT EXISTS / CREATE OR REPLACE / guarded DO blocks).

- **Soft-hide lifecycle pattern (is_hidden + hidden_at):** like is_merged but with a re-hide guard. The hide job only sets is_hidden where `hidden_at IS NULL`; restore (`unhide`) sets `is_hidden=false` but LEAVES `hidden_at` populated — so an admin-restored row is permanently skipped by the nightly hide job. Public sweep is small in practice because most event queries already `.gte('date', today)` (hidden ⇒ >N days past ⇒ already excluded); only queries that fetch PAST events (by-id from trending_scores, featured-without-date, the no-date sitemap lib) genuinely needed the filter. When adding `.neq('is_hidden', true)` to a `.single()` fetch, switch it to `.maybeSingle()` — the filter can now legitimately return zero rows and `.single()` throws.
- **cleanup-old-events was a hole:** it was verify_jwt=true (not in config.toml) with no admin check, so ANY authenticated user could invoke it and trigger deletes. Modernizing a cron/admin edge fn to verify_jwt=false + requireAdminOrApiKey both closes that AND lets the cron service-role bearer + admin-panel JWT through one gate.
- **archived_events (LIKE events INCLUDING ALL) is now STALE** — events has gained geom/is_merged/merged_*/recurrence_*/instance_date/is_hidden that archived_events lacks, so any `INSERT INTO archived_events SELECT *` (legacy cleanup_old_events) now fails on column mismatch. Prefer a NEW explicit-column snapshot table over `SELECT *` into a LIKE-clone.
