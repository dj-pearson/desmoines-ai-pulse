# Ralph Progress Log — Admin Backend Overhaul
Started: 2026-05-20

## Codebase Patterns

### Admin edge-function auth gate (discovered 2026-05-20)
Pattern for admin-only edge functions:
1. `handleCors(req)` → early return on OPTIONS
2. `checkRateLimit(req, { windowMs, max, message })` → 429 + Retry-After
3. Reject non-GET/POST → 405
4. Build service-role client with `Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")`
5. Read `Authorization: Bearer <token>`, call `supabase.auth.getUser(token)`
6. Lookup `profiles.role` and require `admin` or `root_admin`
7. Run queries, return JSON with `Cache-Control: private, max-age=N`
Reference: `supabase/functions/process-stripe-refund/index.ts` and the new
`supabase/functions/admin-home-stats/index.ts`.

### TanStack hook for admin data (discovered 2026-05-20)
Use `supabase.functions.invoke<ResponseType>("fn-name", { body })` (not raw fetch)
so auth headers are attached automatically. Match `staleTime` to the edge
function's `Cache-Control: max-age` to avoid wasted re-fetches. Disable
`refetchOnWindowFocus` for admin dashboards — focus-thrash is noise here.

**Learnings for future iterations:**
- The hotels table did NOT have SEO/GEO columns — they're standard on
  events / restaurants but the hotels migration (20260216000000) shipped
  without them. Pattern for any content table being promoted to a full
  admin vertical: add migration with `ALTER TABLE … ADD COLUMN IF NOT
  EXISTS seo_title TEXT, seo_description TEXT, seo_keywords TEXT[],
  seo_h1 TEXT, geo_summary TEXT, geo_key_facts TEXT[], geo_faq JSONB;`
  Then add the matching columns to `types.ts` Row/Insert/Update by hand.
- Image upload pattern when no dedicated bucket exists: use the shared
  `media` bucket with a per-vertical key prefix (`hotels/<uuid>.<ext>`).
  Avoids creating a new bucket + RLS policies for every vertical.
- `geocode-location` edge function: POST `{ location }` → returns
  `{ latitude, longitude }` or `{ error }`. No auth required (public
  utility). Strategy: only geocode when both lat/lng are blank.
- React Hook Form + Zod number fields: use
  `z.union([z.literal(""), z.coerce.number()…])` so empty inputs are
  valid and get coerced to a clean nullable on save.
- Slug auto-generation pattern: track a `slugTouched` boolean that
  flips when the user edits the slug field directly; while false (and
  not in edit mode), keep regenerating from the name.

## 2026-05-20 — ADMIN-HOTEL-001 (Hotel admin manager: list, search, filter)

Built the first real admin manager from the new PRD. Pattern other
verticals (attractions, playgrounds) should follow.

Shape of the manager component:
1. Debounced search (`useDebounce`, 300ms)
2. Filter row (type / affiliate-presence / sort)
3. Bulk-action bar that only appears when ≥1 row is selected
4. shadcn Table with select-all-on-page + per-row checkbox
5. Status badges column collapsing Featured/Inactive/Affiliate into one cell
6. Sheet panel for read-only detail (edit dialog ships in next story)
7. Pagination (Prev/Next, 25/page, server-side via `offset` + `limit`)
8. Mobile-first responsive: hide Type/Area on <md, Rating on <lg, Updated on <xl

Files:
- `src/components/admin/HotelManager.tsx` (new)
- `src/hooks/useHotels.ts` (added `hasAffiliate` filter + `sortBy: 'updated'`)
- `src/hooks/useDebounce.ts` (new — there was no shared debounce hook)
- `src/pages/AdminHotels.tsx` (replaced placeholder with the real manager)

**Learnings for future iterations:**
- No shared `useDebounce` existed; `SearchAutocomplete.tsx` had a local
  `useDebouncedValue`. Going forward use the new
  `@/hooks/useDebounce` for any admin filter that needs debouncing.
- Don't shoehorn admin verticals into the generic `ContentTable` —
  it's tightly coupled to event-style content (writeup generator,
  domain highlights, event enhancer). Build a focused manager.
- Soft delete pattern for content tables: `UPDATE … SET is_active = false`
  inside an `AlertDialog` confirm. Preserves analytics + lets us
  reactivate without resurrecting from backups.
- When a hook is consumed in many places, prefer additive options
  (new sortBy enum value, new optional filter) over breaking the
  signature. `useHotels` is used by public pages too; the new admin
  filters default to undefined.

**Learnings for future iterations:**
- `lazyWithRetry()` is the local helper in App.tsx that wraps React.lazy
  with chunk-reload retry. Use it (not raw `lazy()`) for all new admin
  pages so Cloudflare cache purges don't strand users on "Loading…".
- ROLE_RANK comparator pattern: keep an enum-like map in the nav module
  and use `ROLE_RANK[user] >= ROLE_RANK[group.minRole]`. Easier to read
  than ad-hoc `includes(["admin", "root_admin"])` arrays.
- AdminPlaceholder pattern: when registering routes ahead of full
  implementation, prefer a single shared placeholder component over 9
  near-identical placeholder pages. Each page becomes a 5-line wrapper
  that names its tracking story.
