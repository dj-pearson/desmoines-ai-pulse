# Lane: ios

**Mission.** The iOS app matches the web on core journeys and never gives App Review a reason to reject it.

**Owns.** ios/DesMoinesInsider/**, ios/DesMoinesInsiderTests/**, ios/project.yml

**Backlog.** Open stories in `prd.json` with prefix IOS-AUDIT-*, XPLAT (iOS half). See `../README.md` for the loop.

## Handoff

None. `/events/date-night` and `/stay/near/<venue>` are the two shared pages that still open on the web. The kids filter (`SearchFilters.kidsOnly`) is not written into a saved search: the web's saved-search keys and the alert job have no kids key, so saving "storytime" with the Kids & family chip keeps only the keyword. If date night gets a native list, `DATE_NIGHT_FILTER` can follow the same shape (an `EventsService` constant, a `SearchFilters` flag, a parity test).
